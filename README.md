# Fitness Coach 1.08

Обновлено в версии 1.08:
- Название и версия проекта обновлены в репозитории: **Fitness Coach 1.08**
- Иконка обновлена в новом 3D-стиле (Luxury Black), бренд **FC** сохранён
- Premium onboarding для первого запуска
- Luxury Black + glassmorphism стиль карточек
- Плавные анимации карточек и кнопок + haptic feedback
- Современный bottom navigation (Главная / Тренировки / Прогресс / AI)
- Регулировка весов в упражнениях: -2.5 / +2.5 / +5
- Таймер 60/90/120/180 сек + пауза / продолжить / остановка
- Раздел «Питание»: можно менять тип еды, граммы, количество порций
- Добавлены ползунки (SeekBar) для граммов и количества порций
- OpenRouter AI Coach, статистика/PR, замеры и календарь

Сборка: открыть проект в Android Studio → Gradle Sync → Build/Run.
