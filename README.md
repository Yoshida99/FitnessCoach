# FitnessCoach

Тренировочный дневник с AI-тренером. Один экран-активность, без сторонних библиотек.

## Установка на телефон
Каждая отправка в ветку `claude/fitness-couch-v2` собирает APK на GitHub и выкладывает его в Releases:
https://github.com/Yoshida99/FitnessCoach/releases/tag/fitness-couch-v2-latest

Открой ссылку с телефона, скачай `FitnessCoach.apk` и установи.

## Запуск из Android Studio
Открой папку проекта, дождись синхронизации Gradle и нажми Run.

Это отдельное приложение (внутренний идентификатор `com.ruslan.fitnesscouch` оставлен прежним, чтобы обновления ставились поверх и сохраняли данные): оно ставится рядом с Fitness Coach 1.08 из ветки `master` и не затрагивает его данные.

## Что где лежит
- `Program.java` — программа тренировок: упражнения, подходы, диапазон повторов, стартовый вес, шаг веса, отдых, подсказки по технике. Менять программу — только здесь.
- `Store.java` — все данные: журнал подходов, замеры, чат, резервная копия.
- `Ai.java` — запросы к OpenRouter.
- `MainActivity.java` — экраны и интерфейс.
- `LineChart.java` — график.
- `Figure.java`, `Moves.java`, `ExerciseView.java` — анимации упражнений (позы задаются углами суставов в `Moves.java`).

## Как пользоваться журналом
- Нажатие на подход — записан с верхним числом повторов, сразу стартует отдых.
- Ещё нажатие — минус один повтор. Удержание — ввести число вручную.
- Вес меняется кнопками − / + или нажатием на само число.
- Когда в прошлый раз все подходы сделаны по верхней границе, карточка предлагает поднять вес.
